# 智能选股助手 (StockAdvisor)

## 产品概述

智能选股助手是一款基于多因子量化模型的A股智能分析工具，实时获取全市场行情数据，支持「综合推荐」和「短期看涨」两种分析策略，自动筛选出高评分标的并给出推荐星级和详细分析报告。

## 核心功能

### 1. 多数据源行情获取

支持4个主流财经数据源，可在界面中自由切换：

| 数据源 | 特点 |
|--------|------|
| 东方财富 (默认) | 数据最全面，支持所有版块 |
| 新浪财经 | 老牌稳定，响应快 |
| 腾讯财经 | 实时性好，延迟低 |
| 网易财经 | 历史数据丰富 |

### 2. 七大市场版块覆盖

| 版块 | 说明 |
|------|------|
| A股 | 沪深主板 + 科创板 + 创业板 |
| ETF基金 | 场内交易型开放式基金 |
| LOF基金 | 上市型开放式基金 |
| 黄金贵金属 | 黄金、白银等贵金属品种 |
| 期货 | 原油、贵金属等期货品种 |
| 港股通 | 沪深港通标的 |
| 中概美股 | 在美上市中国概念股 |

### 3. 双策略分析模型

支持两种分析策略，可在界面「策略」下拉框中切换：

#### 策略一：综合推荐（默认）

六维稳健型评分，适合中长期选股：

| 分析维度 | 分值 | 分析内容 |
|----------|------|----------|
| 动量因子 | 0-20分 | 涨跌幅趋势，理想涨幅1%-5%，惩罚极端波动 |
| 量能因子 | 0-20分 | 换手率、成交活跃度评估 |
| 估值因子 | 0-25分 | 市盈率(PE)、市净率(PB)综合评估 |
| 技术因子 | 0-15分 | 振幅、日内价格位置分析 |
| 市值因子 | 0-20分 | 总市值规模与稳定性 |
| K线趋势 | 0-30分 | MA均线、RSI(14)、MACD(12,26,9) (深度分析模式) |

**综合评分公式：**
- 基础模式：动量 + 量能 + 估值 + 技术 + 市值 = 满分100
- 深度模式：基础分 × 0.7 + 趋势分 × 0.3 × (100/30) = 满分100

#### 策略二：短期看涨

三维激进型评分，专注短期上涨信号，自动启用K线深度分析：

| 分析维度 | 分值 | 分析内容 |
|----------|------|----------|
| 短期动量 | 0-35分 | 重点关注3%-7%强势拉升，放量上涨信号 |
| 短期量能 | 0-35分 | 换手率5%-10%为理想放量区间，资金活跃进场 |
| 短期技术 | 0-30分 | 收盘价靠近最高价(买盘强)、适度振幅(交易机会) |
| K线趋势 | 0-30分 | MA5突破MA20、RSI 50-65强势区、MACD金叉、连续阳线、放量上涨天数 |

**短期评分公式：**
- 快照分 × 0.4 + K线趋势分 × 0.6 × (100/30) = 满分100

**核心选股信号：**
- 放量拉升（换手率5%-10%且涨幅3%-7%）
- 强势收盘（收盘价靠近日最高价）
- 连续阳线（近5日连续上涨天数）
- 放量上涨（量价齐升天数）
- MACD金叉 + 柱状图翻红
- MA5向上突破MA10/MA20

> 注：短期策略不考虑估值因子和市值因子，因为短期走势与基本面估值相关性较低。

### 4. 星级推荐系统

| 评分区间 | 星级 | 推荐级别 |
|----------|------|----------|
| ≥ 80分 | ★★★★★ | 强烈推荐 |
| ≥ 68分 | ★★★★☆ | 推荐 |
| ≥ 55分 | ★★★☆☆ | 关注 |
| ≥ 40分 | ★★☆☆☆ | 一般 |
| < 40分 | ★☆☆☆☆ | 不推荐 |

### 5. K线深度分析 (可选)

开启深度分析后，对排名靠前的股票额外获取K线数据，计算：
- **MA均线**：MA5、MA10、MA20 多头/空头排列判断
- **RSI(14)**：超买(>70)、超卖(<30)、中性区间判断
- **MACD(12,26,9)**：DIF、DEA、柱状图金叉/死叉判断
- **综合趋势评分**：三个指标加权得出趋势得分

### 6. 详细分析报告

点击列表中的股票，在详情区域展示完整分析报告，包含：
- 各维度得分明细
- 技术指标数值（MA、RSI、MACD）
- 综合性文字评语
- 推荐标签（如：价值低估、量能充沛、趋势向好等）

### 7. CSV导出

将分析结果导出为CSV文件，包含21+列数据：
- 基础信息：代码、名称、现价、涨跌幅
- 交易数据：换手率、振幅、成交额
- 估值指标：市盈率、市净率、总市值、流通市值
- 评分数据：综合评分、星级、推荐标签
- 技术指标：MA5、MA10、MA20、RSI14、MACD_DIF、MACD_DEA、MACD柱状

## 界面说明

### 顶部控制栏（第一行）
- **数据源**：选择行情数据接口
- **版块**：选择市场版块
- **排序**：成交额/涨跌幅/换手率排序
- **数量**：获取股票数量（50-500）
- **策略**：综合推荐 / 短期看涨

### 顶部控制栏（第二行）
- **深度分析(K线)**：是否启用K线趋势分析
- **排除ST**：自动过滤ST、*ST股票
- **获取并分析**：开始分析
- **停止分析**：中途停止（分析中可用）
- **导出CSV**：导出结果（注册用户可用）
- **进度条**：分析进度

### 右上角注册状态
- 显示注册状态（已注册/试用版）
- 显示剩余次数或注册按钮

### 结果列表（12列）
序号、代码、名称、现价、涨跌幅、换手率、市盈率、市净率、总市值、评分、星级、推荐标签

### 详情区域
点击股票后显示完整分析报告文字
